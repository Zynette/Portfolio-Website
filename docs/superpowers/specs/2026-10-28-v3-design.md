# Portfolio V3 design

The user supplied the complete V3 brief and authorized implementation and publication after checks. This design records implementation choices within that authorization.

Preserve framework-free HTML, CSS and JavaScript and Cloudflare Pages. A plum opening composition combines very large editorial name typography with an original parametric ribbon, representing different views of the same system. Three keyboard-operable perspectives change the sculpture without hiding content or delaying navigation. Parchment, blush and muted champagne provide contrast. Self-host a serif alongside the existing sans. No stock photos, generic cards, autoplay or intro gate.

Follow with a wide real development screenshot, alternating project compositions, concise experience and a private contact section. Keep verified project maturity explicit. CareerOS remains a design study. Kitchenly remains an unverified experiment. Case studies receive the same visual system and natural copy editing.

Remove résumé files and links, audit historical exposure without history rewriting, and return 410 through a Cloudflare advanced-mode Worker. The Worker handles a same-origin contact POST with server validation, honeypot, Turnstile verification and a Resend delivery adapter. Recipient, sender, provider key and Turnstile secret are server secrets. Missing configuration must return unavailable, never success. Success means provider acceptance, not inbox delivery. Turnstile supplies abuse protection; document Cloudflare rate-limit setup if available.

Alternative directions considered: blush monochrome would be less distinct; illustrated personal imagery would require unverified assets. The chosen typographic/sculptural identity communicates the requested feminine technology aesthetic without invented personal evidence.

Deployment: use GitHub Actions to test then Wrangler-upload dist to the existing direct-upload Pages project. Keep domain and HTTPS unchanged. Credentials must be set in GitHub secrets, not source. Verify the domain, removed URLs, contact provider acceptance and actual inbox arrival before describing production as complete.
